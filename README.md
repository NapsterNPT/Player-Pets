## Now you can have your custom pet wherever you want!

![Downloads](https://img.shields.io/modrinth/dt/Player-Pets?color=blue)  ![Release](https://img.shields.io/github/v/release/NapsterNPT/player-pets)

You can easily load a custom model with a resource pack if you want to read more, read the documentation down the file.

You can download the mod from [Modrinth](https://modrinth.com/mod/player-pets) or the [GitHub Repository](https://github.com/NapsterNPT/Player-Pets); any other source will be marked as unofficial.

If you want to see the source code or report and issue [Click Here](https://github.com/NapsterNPT/Player-Pets).

## Documentation on how to load your custom pet.
1. Create a texture pack with this structure:
    ```
    Tutorial Custom Pet
    ├── assets
    │   └── playerpets
    │       ├── models
    │       │   └── (The JSON model will go here)
    │       └── textures
    │           └── (Textures will go here)
    ├── pack.mcmeta
    └── pack.png
    ```
   ### ⚠️ Note that the JSON file and the texture need to have the same name.
